# 모이온(MOION) 검산 사례
최종 갱신: 2026-11-23 (1-4·1-5·9-10·11-13·11-14·12-1~12-4·13-1~13-4 추가, 1단계 API 명세 확정안 37개 연결) / 기준: 확정 정책 문서 v31

새 규칙을 내거나 문구·불변식을 고칠 때 아래 사례를 모두 넣어 계산하고, 기대값과 다르면 규칙을 다시 본다. 백엔드 단위·통합 테스트의 기준값으로도 쓴다.

> 모든 값은 구현 전에 계산한 **기대 결과**다. 아직 단위·통합 테스트로 실행하지 않았다. 테스트를 실행하면 해당 사례 옆에 실행 근거(커밋·테스트 이름)를 따로 적는다.

## 4. 금액 정정 배분 (POL-011)
기본: 고기 2만 원 × 6인분 = 선결제 120,000원, 4인분 제공 → 정정 총액 40,000원

| # | 입력 | 기대값 | 확인 포인트 |
|---|---|---|---|
| 4-1 | 6명 각 20,000원 | 4명 6,667원, 2명 6,666원, 합계 40,000원 | 나머지가 모두 같아 예약자 → 결제 완료 순 → 결제 ID 순으로 1원 |
| 4-2 | C 60,000원, 나머지 4명 각 15,000원 | C 20,000원, 4명 각 5,000원, 합계 40,000원 | 남는 원 없음 |
| 4-3 | 4-2에서 정정 총액 1원 | C 1원, 나머지 0원 | 정수 나머지가 가장 큰 결제 건부터 1원 |
| 4-4 | 4-1에서 매장이 A에게 현장에서 5,000원을 이미 반환(A 정정액 6,667원) | A 앱 환불 1,667원, 나머지 5명 자기 정정액 그대로. 앱 환불 합계 35,000원, 정정 총액 40,000원, 매장 지급 대상 85,000원, 매장 최종 몫 80,000원 | 선결제 120,000 = 지급 대상 85,000 + 앱 환불 35,000. 정정 총액 40,000 = 앱 환불 35,000 + 현장 반환 5,000. 현장 반환을 선결제 식에 다시 넣으면 125,000원이 되어 틀린다 |
| 4-5 | 앱 환불액 0원인 결제 건 | PG 요청 없음 | |

금지 반례: 몫 기준으로 다시 나누고 나머지를 예약자에게 몰아주면, 2만 원 × 6명·정정 총액 119,999원에서 1몫 19,999원 + 나머지 5원 → 예약자 환불 20,004원으로 결제액 20,000원을 넘는다.
